# Product Vision

## What

Multi-tenant personal-data intelligence platform. Users import professional-network data (starting with LinkedIn), system normalizes into canonical model, builds knowledge graph, generates analytics, provides AI agent to query and reason over private data enriched with permitted public-web information.

## Why

Professional data scattered across CSVs, inboxes, CRMs, calendars. No unified view. No intelligence layer. No natural-language interface to own professional relationship data.

## Transformation

```
RAW USER DATA
→ INGESTION → SCHEMA DETECTION → NORMALIZATION → ENTITY RESOLUTION
→ CANONICAL DATABASE → KNOWLEDGE GRAPH → ANALYTICS
→ VECTOR/SEMANTIC INDEX → INTELLIGENCE ENGINE → AI AGENT
→ DASHBOARDS / CHAT / RESEARCH
```

## North Star

"My professional data has become an intelligent database that understands my relationships, communication, career history, network, activity, and opportunities—and I can ask it questions in natural language."

## Evolution

1. DATA IMPORTER
2. PERSONAL INTELLIGENCE ENGINE
3. RELATIONSHIP INTELLIGENCE PLATFORM
4. AI-POWERED PROFESSIONAL OPERATING SYSTEM

## Moat

Not chat UI. Moat = canonical professional-data model + entity resolution + temporal relationship graph + provenance + intelligence layer. LinkedIn is first connector, not entire product.
